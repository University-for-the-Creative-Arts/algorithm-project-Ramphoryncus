# NewGrooveGenSynth

# Procedural Audio Mini-Project

## Overview

This project demonstrates a procedural audio system developed in Unreal Engine 5 using C++. The synthesiser generates music in real time using procedural algorithms rather than pre-recorded audio. The system allows the user to interactively modify parameters such as tempo, musical scale and random seed while the application is running.

## Controls

| Key | Action |
|------|--------|
| **W** | Increase BPM |
| **S** | Decrease BPM |
| **A** | Cycle Musical Scale |
| **D** | Generate New Random Seed |

- `Source/` – Unreal Engine C++ source files.
