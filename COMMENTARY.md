# Procedural Systems Mini-Project Commentary

## Overview

This project demonstrates a procedural audio system developed in Unreal Engine 5 using C++. Rather than playing pre-recorded music, the application generates musical content in real time using mathematical algorithms. The system creates an evolving soundscape consisting of an arpeggiated melody, sustained pad sounds and simple procedural percussion. Runtime controls allow the user to alter the generated music by changing the tempo, musical scale and random seed.

## How the System Works

The project uses Unreal Engine's `USynthComponent` and `ISoundGenerator` classes to generate audio directly on the audio rendering thread. A custom component (`UGrooveSynthComponent`) stores user-adjustable parameters such as beats per minute (BPM), musical scale, brightness, density and random seed.

When the synthesiser starts, it creates an instance of `FGrooveSoundGenerator`, which continuously produces audio samples that are sent to Unreal Engine's audio mixer. The generator maintains internal timing counters based on the current BPM, allowing notes and percussion to be triggered at musical intervals.

The melodic content is generated using a Brownian random walk. Rather than selecting completely random notes, the algorithm moves gradually through the current musical scale, producing melodies that sound more natural and coherent. Four different musical scales are available: Ionian, Dorian, Minor Pentatonic and Harmonic Minor.

Each voice is synthesised from simple oscillators with ADSR (Attack, Decay, Sustain, Release) envelope shaping. Additional processing includes soft clipping, simple filtering and a lightweight feedback reverb to improve the overall sound.

## Tools, Algorithms and APIs Used

The project was implemented entirely in C++ using Unreal Engine 5.6.

Major Unreal Engine systems used include:

- USynthComponent
- ISoundGenerator
- Unreal Audio Mixer
- BlueprintCallable functions
- Actor Components
- Enhanced runtime parameter control

Algorithms and techniques used include:

- Brownian random walk melody generation
- ADSR envelope generation
- Procedural oscillator synthesis
- Randomised percussion triggering
- Simple digital filtering
- Soft clipping
- Real-time parameter interpolation

## Procedural and Generative Features

The procedural nature of the project comes from the fact that no musical recordings are stored or played back. Every note is calculated while the application is running.

The random seed allows different musical patterns to be generated each time while still producing musically valid results. Runtime controls allow the user to change the tempo and musical scale while the system is playing, demonstrating interactive procedural generation.

Unlike traditional audio playback, the music is continuously generated by algorithms rather than fixed compositions. This allows the output to evolve over time while remaining within the chosen musical scale.

## Conclusion

This project demonstrates the use of procedural audio generation within Unreal Engine using modern C++. It combines simple digital signal processing techniques with procedural algorithms to create interactive, dynamically generated music. The implementation demonstrates how mathematical and algorithmic approaches can be used to generate audio content in real time without relying on pre-recorded assets.
